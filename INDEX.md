## 🎯 Key Concepts

### 15 Quality Check Rules
Data quality checks performed on clinical datasets:
1. **HEADER_DUPLICATE** - Duplicate column names
2. **HEADER_EMPTY** - Missing headers
3. **ROW_EMPTY** - Completely blank rows
4. **COLUMN_EMPTY** - Completely blank columns
5. **MISSING_VALUES** - Missing data statistics
6. **EXACT_DUPLICATE_ROWS** - Identical records
7. **DUPLICATE_ID** - Non-unique identifiers
8. **MIXED_TYPES** - Mixed data types in column
9. **NUMERIC_PARSE_AMBIGUITY** - Unclear number format
10. **INVALID_DATE_CANDIDATE** - Unparseable dates
11. **DATE_ORDER** - End before start logic error
12. **CONSTANT_COLUMN** - Only one unique value
13. **HIGH_CARDINALITY_CATEGORY** - Many unique values
14. **OUTLIER_IQR_FLAG** - Potential extreme values
15. **POSSIBLE_OUTCOME_LEAKAGE** - Suspicious column names

For details → [README.md](README.md) "What It Checks"

### 3 Severity Levels
- **🚫 BLOCKER** (red) - Must fix before analysis
- **⚠️ WARNING** (yellow) - Should review
- **ℹ️ INFO** (blue) - For reference

### Privacy Model
- ✅ 100% local browser processing
- ✅ No data uploads
- ✅ No server calls
- ✅ No tracking or analytics
- ✅ No user accounts

For details → [docs/privacy-and-limitations.md](docs/privacy-and-limitations.md)
